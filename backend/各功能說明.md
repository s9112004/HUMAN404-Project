# Feature Overview (Based on servertest.py)

This document describes each API endpoint implemented in `servertest.py` and how it behaves.

## Database

### POST /db/search
- Purpose: Search `document_store` records by optional keyword.
- Input: JSON body with `keyword` (optional), `limit` (1?100), `sort` (`newest` or `oldest`).
- Behavior:
  - If `keyword` is provided, it searches both `title` and `content` with `LIKE`.
  - Sorts by `created_at` then `id` to ensure stable ordering.
  - Limits the number of results using `limit`.
- Response:
  - If no results: `{ "result": "?????" }`
  - Otherwise: `{ count, data, formatted_list }`

### POST /db/add
- Purpose: Insert a new document.
- Input: JSON body with `title` and `content`.
- Behavior:
  - Inserts into `document_store (title, content)`.
  - Commits on success; rollbacks on error.
- Response: Success or error message.

### POST /db/update
- Purpose: Update an existing document by id.
- Input: JSON body with `id`, and optional `title` / `content`.
- Behavior:
  - Updates only provided fields.
  - Allows empty strings as valid updates.
  - Commits on success; rollbacks on error.
- Response: Success or error message.

### POST /db/delete
- Purpose: Delete a document by id.
- Input: JSON body with `id`.
- Behavior:
  - Deletes the row from `document_store`.
  - Commits on success; rollbacks on error.
- Response: Success or error message.

## S3

### POST /aws/s3/list_buckets
- Purpose: List all S3 buckets.
- Input: None.
- Behavior: Calls `list_buckets` and returns bucket names.
- Response: `{ "buckets": [ ... ] }` or error.

### POST /aws/s3/list_files
- Purpose: List objects in a specific bucket.
- Input: JSON body with `bucket_name`.
- Behavior: Calls `list_objects_v2`.
- Response: `{ "files": ["key (size: N bytes)", ...] }` or "????" if empty.

### POST /aws/s3/create_bucket
- Purpose: Create a new bucket in the configured region.
- Input: JSON body with `bucket_name`.
- Behavior:
  - If region is `us-east-1`, calls `create_bucket` without LocationConstraint.
  - Otherwise includes `CreateBucketConfiguration` with the session region.
- Response: Success or error message.

### POST /aws/s3/upload_base64
- Purpose: Upload files via JSON Base64 (recommended for Dify Agent).
- Input (JSON):
  - `bucket_name`
  - `file_name`
  - `content_base64`
  - `content_type` (optional)
- Behavior:
  - Decodes Base64 to bytes and uploads using `put_object`.
  - Infers content-type from filename when not provided.
- Use case: Dify Agent uploads where file-type parameters are not supported.

- Input (multipart):
  - `bucket_name` (text)
  - `file` (binary)
  - `file_name` (optional override for object key)
- Behavior:
  - Uses `file_name` if provided, otherwise `file.filename`.
  - Attempts to determine content-type from upload or filename.
  - Streams file directly to S3 via `upload_fileobj`.

### POST /aws/s3/delete_file
- Purpose: Delete an object from a bucket.
- Input: JSON body with `bucket_name`, `file_name`.
- Behavior: Calls `delete_object`.
- Response: Success or error message.

### POST /aws/s3/download_file
- Purpose: Return a presigned download URL.
- Input: JSON body with `bucket_name`, `file_name`.
- Behavior:
  - Generates a presigned URL (GET) with 900s expiry.
  - Does not stream file content directly.
- Response: `{ url, method, bucket, key }` or error.

### POST /aws/s3/delete_bucket
- Purpose: Delete a bucket (must be empty).
- Input: JSON body with `bucket_name`.
- Behavior: Calls `delete_bucket`.
- Response: Success or error message.

## EC2

### POST /aws/ec2/list
- Purpose: List all EC2 instances in structured form.
- Input: None.
- Behavior:
  - Calls `describe_instances`.
  - Returns `id`, `name` (from tag), `state`, `type`, `public_ip`, `private_ip`, and `tags`.
- Response: `{ "instances": [ ... ] }` or error.

### POST /aws/ec2/get
- Purpose: Get details for a single instance.
- Input: JSON body with `instance_id`.
- Behavior: Calls `describe_instances` for one ID and returns structured fields.
- Response: Instance object or error.

### POST /aws/ec2/wait_state
- Purpose: Wait until an instance reaches a target state.
- Input: JSON body with `instance_id`, `target_state` (running/stopped/terminated).
- Behavior: Uses EC2 waiter to block until the target state is reached.
- Response: Success or error message.

### POST /aws/ec2/launch
- Purpose: Launch a new EC2 instance.
- Input: JSON body with optional `instance_type`, `ami_id`, and `name`.
- Behavior:
  - Creates one instance.
  - Sets the Name tag to `name` if provided, otherwise uses `AI-Created-Server`.
- Response: Instance ID or error.

### POST /aws/ec2/power
- Purpose: Start/stop/reboot an instance.
- Input: JSON body with `instance_id`, plus query param `action` (start/stop/reboot).
- Behavior: Calls the corresponding EC2 action.
- Response: Status message or error.

### POST /aws/ec2/modify_type
- Purpose: Change instance type.
- Input: JSON body with `instance_id`, `new_instance_type`.
- Behavior:
  - Requires the instance to be `stopped`.
  - Calls `modify_instance_attribute`.
- Response: Success or error message.

### POST /aws/ec2/terminate
- Purpose: Terminate (delete) an instance.
- Input: JSON body with `instance_id`.
- Behavior: Calls `terminate_instances`.
- Response: Status message or error.
